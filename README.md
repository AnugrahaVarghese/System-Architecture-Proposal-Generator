🏗️ System Architecture Proposal Generator

An AI-powered system architecture assistant that transforms API documentation and technical design requirements into structured infrastructure proposals and Infrastructure-as-Code (IaC).

📌 Project Overview

System Architecture Proposal Generator is an AI-driven application designed to simplify the process of system architecture planning and infrastructure design.

The application uses Google's Gemini AI to analyze API documentation, understand technical requirements, and generate architecture proposals. It aims to reduce manual effort in designing system infrastructure by automating requirement analysis and infrastructure planning.

The project explores how generative AI can assist developers and system architects in translating technical specifications into practical architecture solutions.

✨ Key Features

- AI-Powered Architecture Generation: Uses AI to generate system architecture proposals from technical requirements.
- API Documentation Analysis: Processes API documentation as an input for architecture planning.
- Design Constraint Processing: Considers technical requirements and design constraints when generating proposals.
- Infrastructure-as-Code Generation: Supports generating infrastructure configuration code.
- Automated Validation: Designed to validate generated infrastructure configurations.
- Self-Correction Workflow: Incorporates an iterative approach to identifying and improving generated outputs.
- Interactive User Interface: Provides an interface for interacting with the architecture generation workflow.

⚙️ How It Works

The application follows an AI-assisted architecture generation workflow:

1. Input Requirements: Provide API documentation and system design constraints.
2. Requirement Analysis: AI analyzes the supplied technical information.
3. Architecture Generation: Generate a proposed system architecture.
4. IaC Generation: Translate architecture decisions into infrastructure configuration code.
5. Validation: Evaluate the generated output.
6. Improvement: Use an iterative correction process to improve the generated configuration.

🚀 Getting Started

Prerequisites

- Node.js
- npm
- Google Gemini API key

Installation

1. Clone the repository:
   
   git clone https://github.com/AnugrahaVarghese/System-Architecture-Proposal-Generator.git

2. Navigate to the project directory:
   
   cd System-Architecture-Proposal-Generator

3. Install dependencies:
   
   npm install

4. Configure your environment variables.
   
   Create a ".env.local" file and add:
   
   GEMINI_API_KEY=your_gemini_api_key

5. Start the development server:
   
   npm run dev

6. Open the local development URL displayed in your terminal.
